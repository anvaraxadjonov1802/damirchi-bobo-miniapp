# Damirchi Telegram Bot

Minimal Telegram bot for Damirchi online ordering.

## Setup

```bash
cd bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Create `.env` from `.env.example`.

## Run

```bash
python main.py
```

## Features

- `/start` cleans recent private chat messages.
- Bot menu button opens the Web App.
- Inline button opens the Web App.
- Operator group can update order status.
